# 📝 PROJECT MANIFESTO: NotesBazi

## 🚀 Project Overview
NotesBazi is a premium Notes Management application built with high-performance technologies.

## 🛠 Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **State/Auth/DB**: Supabase (using `@supabase/ssr` and `@supabase/supabase-js`)
- **Styling**: Tailwind CSS 4 (Modern, fast, and sleek)
- **UI Components**: Shadcn UI (Radix based)
- **Animations**: Framer Motion & `tw-animate-css`
- **Charts**: Recharts
- **AI Integration**: Google Gemini SDK

## 🎨 Design Principles
- **Aesthetics**: Glassmorphism, smooth gradients, and micro-animations.
- **Responsiveness**: Mobile-first, but desktop-premium.
- **Dark Mode**: Default and highly polished.

## 🤝 Team Roles
- **Lead (Antigravity)**: UI implementation, complex animations, and overall project orchestration.
- **Architect (Claude)**: SQL/Schema design, edge cases, and architectural integrity check.

## 📈 Goals
1. Implement a complete "Category" and "Tag" management system.
2. Build a stunning dashboard for note analytics using Recharts.
3. Ensure high security for user-generated content via Supabase RLS.
